A disorganized but highly valuable repository with a dynamic table of contents to access different functions. Based on the textbook C. Chapra and R. P. Canale, Numerical Methods for Engineers, Seventh Edition, McGraw-Hill, New York, 2015. Includes methods for: Numerical differentiation, numerical integration, linear regressions, Taylor series, Richardson extrapolation, bracketing and open methods, interpolation, initial value problems (IVPs), systems of linear equations, boundary value problems (BVPs), linear programming, optimization, and contour plots.
